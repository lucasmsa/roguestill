# roguestill

Caps how long you play roguelikes per day. A background daemon watches the game process and its save files, warns for 10 seconds, then closes the game when the daily budget is spent. A macOS menu bar app shows the countdown over the game and a WidgetKit widget shows time left. The name plays on "hold still".

Currently supports Noita (run through CrossOver on macOS). Design decisions are in `docs/adr`.

## Layout

- `crates/roguestill-core`: rule model, budget, Noita save reader.
- `crates/roguestilld`: daemon that polls, enforces and serves status on a Unix socket.
- `crates/roguestill`: CLI (`roguestill status`, `roguestill rules`).
- `app/RoguestillBar`: Swift menu bar app, overlay and widget. See its README.
- `config/rules.example.toml`: example rules.
- `packaging/`: launchd plist template.

## Install

```sh
DEVELOPMENT_TEAM=<your team id> scripts/build-app.sh
```

This builds `Roguestill.app` with the daemon inside and opens it from `~/Applications`. On first launch the app registers the daemon as a login agent; approve it once in System Settings > Login Items. The daemon writes default rules (Noita, 90 minutes a day) to `~/Library/Application Support/roguestill/rules.toml` if none exist; edit that file to change them.

## Build

```sh
cargo test --workspace
cargo build --release
```

The Swift app needs macOS 14+ and Xcode. The widget needs an Xcode project generated by [xcodegen](https://github.com/yonaskolb/XcodeGen) and your own signing team:

```sh
cd app/RoguestillBar
DEVELOPMENT_TEAM=<your team id> xcodegen generate
```

Change the bundle IDs and the App Group (`group.com.lucasmsa.roguestill`, also in `Snapshot.swift`) to your own.

## Game icon

The overlay shows the game's own icon when `app/RoguestillBar/Sources/RoguestillBar/Resources/<game>.png` exists (for Noita, `noita.png`). The icon belongs to its publisher and is not distributed here; copy it from your own install. Without it the overlay shows a grey shield.
